## ✨ Overview

The **Osdag Bridge Deck Designer** empowers structural engineers, researchers, and students to interactively design bridge decks with ease. By providing real-time visual feedback, users can seamlessly modify design parameters and immediately observe the structural impact on both the cross-section and plan views of the bridge.

## 🚀 Key Features

* **🎨 Real-time Visualization:** Dynamic SVG rendering that adapts instantly to your numerical inputs.
* **📏 Unit Versatility:** Seamlessly toggle between **Metric (m)** and **Imperial (ft)** units on the fly.
* **💾 Smart Auto-Save:** Never lose your work—your design progress is automatically saved to local storage.
* **👁️ Accessibility First:** Includes a dedicated **High Contrast mode** for improved visibility and inclusivity.
* **📱 Responsive Design:** A fully responsive and intuitive UI built with `shadcn/ui` and Tailwind CSS.

## 🏁 Getting Started

Follow these instructions to set up the project locally on your machine.

### Prerequisites

Ensure you have the following installed:
* [Node.js](https://nodejs.org/) (v18 or higher)
* npm (v9 or higher)

### Installation

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/irajverma/Osdag-Bridge-Deck-Designer.git](https://github.com/irajverma/Osdag-Bridge-Deck-Designer.git)
   cd Osdag-Bridge-Deck-Designer
## Install dependencies:

Bash
npm install
Start the development server:

Bash
npm run dev
📦 Build & Deploy
To create a production-ready build and deploy it to Firebase:

## Create the production build:

Bash
npm run build
Deploy to Firebase Hosting:

# Bash
firebase deploy --only hosting
